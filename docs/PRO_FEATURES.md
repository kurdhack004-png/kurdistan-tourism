# Kurdistan Tourism PRO Roadmap

Included in V12 bundle:
- Flutter mobile application
- Node.js API with JWT + role-based admin
- SQLite development database; production can migrate to PostgreSQL/PostGIS
- Location CRUD and verification
- Accommodation, booking, payment-status abstraction
- Reviews and favorites
- Admin analytics
- Optional local Ollama AI Tourism Assistant
- Docker Compose development API
- Dependency-free Admin Dashboard
- Weather integration endpoint placeholder
- Push-notification integration point

Recommended production steps:
1. PostgreSQL/PostGIS
2. Object storage for images
3. Firebase Cloud Messaging credentials
4. Real payment gateway credentials
5. Live weather provider key if needed
6. HTTPS + domain + reverse proxy
7. Backups and monitoring
