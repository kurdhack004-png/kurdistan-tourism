# Kurdistan Tourism API PRO v12

Production-oriented API companion for the Flutter app. Includes JWT authentication, roles, locations CRUD, accommodations, bookings/payments abstraction, reviews, favorites, admin statistics, and optional local Ollama AI.

## Windows
1. Install Node.js 20+.
2. Open this folder in terminal.
3. `copy .env.example .env`
4. `npm install`
5. `npm start`
6. API: `http://localhost:8000/api/health`

Default admin: `admin@kurdistantourism.local` / `ChangeMe123!` (change immediately in `.env`).

For Android Emulator use `http://10.0.2.2:8000/api`; for a real phone use your PC LAN IP, e.g. `http://192.168.1.10:8000/api`.
